Privacy Policy

Effective date: 2026-10-21

Cause Found is a video channel run by an individual based in Montenegro (the "operator"). This policy covers this website and the "Postiz" application, a scheduling tool the operator uses to manage the channel's social media accounts.

This website

This website collects no personal data. It sets no cookies, runs no analytics and loads no third-party scripts, fonts or other third-party requests. It has no forms, accounts or comments. The site is hosted on GitHub Pages, which, like any web host, may keep technical server logs that the operator does not receive or control. If you email us, we use your address only to reply.

The Postiz application

Postiz is a self-hosted scheduling application. The operator runs it solely to manage the operator's own social media accounts. It is not offered to the public: no other users can sign in, and no one else's accounts or data are handled.

Google and YouTube data

When the operator connects a Google account, the application uses Google APIs to access the operator's own YouTube channel data: the channel list, video uploads, scheduling and analytics. This data is used only to publish and measure the operator's own videos.

  • Data is processed on the operator's own computer.
  • It is not sold and not shared with anyone else.
  • It is retained only as long as needed to schedule and measure uploads.
  • Access can be revoked at any time at https://myaccount.google.com/permissions.

The Postiz application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

TikTok

The operator may connect TikTok accounts that the operator owns. The same rules apply: the application accesses only the operator's own account, to publish videos and read their performance. Data stays on the operator's computer, is not sold or shared, and is kept only as long as needed. Access can be removed at any time in the TikTok account's settings.

Meta (Facebook and Instagram)

The operator may connect Facebook Pages and Instagram accounts that the operator owns. The same rules apply: only the operator's own accounts are accessed, to publish videos and read their performance. Data stays on the operator's computer, is not sold or shared, and is kept only as long as needed. Access can be removed at any time in the connected-apps settings of the account.

Deleting data

Revoking access on the platform, or disconnecting the account in Postiz, ends the application's access. To ask for stored data about a connected account to be deleted, email the address below.
